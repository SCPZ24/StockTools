# v1版本概念

> 这里记录新增的功能概念

## 板块抓取

工具随着st init或者st update抓取过去一年或者新的一天的各个概念板块的行情数据。（需要具体研究现有接口是可以立即调取过去所有天的板块行情。如果不可以，就从用户安装部署这个程序的第一天开始抓取。）

然后计算涨幅榜。排序每天涨幅前10的概念板块，存入数据库。

## 热点板块自动更新

如果一个板块在连续10天里有大于7天上榜，或者过去连续三天在涨幅榜上，就认定为是短期小热点。

如果一个板块是短期小热点，并且里面罗列了超越30只（或者更多？需要具体研究）股票，并且里面有千亿市值以上的股票，那我们鉴定为这个股票是市场主线。

## 关于数据库

需要一张表存储每个概念板块。比如0-CPO，1-半导体，2-农业等等。我们称为概念板块索引表。

每日热点版块是另一张表，每一行表示一个交易日。里面存储日期，以及10个热门板块在概念板块索引表的序号。
