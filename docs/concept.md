# 概念文档


## 理念

- 只做中长线
- 只做多
- 每天花10分钟研究股票，不占用我大量时间
- 只做确定性高的形态，这里直接列举：低位箱体突破；上升通道；独立行情；爆量吸筹


## 选股能力

同花顺已经提供快速筛选功能：
- 上升通道
- 平台突破(箱体突破)

我们的产品需要补齐这些功能：
- 爆量吸筹
- 独立行情
- 箱体突破

## 功能点


### 选股

扫描器全部做：
- 爆量吸筹
- 独立行情
- 箱体突破
- 上升通道


### 记录

用户有时候看到一些形态，想持续关注。但是很容易忘记。
我们可以把股票注册进“记录”池，持续关注后续走势，满足用户好奇心的同时，增长对于技术形态的认识。


### 买入提醒

用户观察到机会后，注册股票进入自己的关注列表（就像同花顺的自选列表）。
我们会启动Agent来分析是否应该买入。


### 卖出提醒

每次买入后，用户注册进自己的持仓。
我们会启动Agent来分析是否应该卖掉。


## 形态

不是 Web，是 CLI + TUI 混合的形式；第一版先只实现 CLI 指令，TUI 后置。

这是一个终端项目。`setup.sh` 会引导用户把 `st` 指令写入 `~/.zshrc` 或 `~/.bashrc`，并创建工作目录。默认工作目录为 `~/.stock_tools`，用户也可以在 setup 阶段自定义。

数据持久化放在工作目录内：
- 行情、关注池、持仓、AI 日志：`<workdir>/database.db`
- 模型配置：`<workdir>/config.db`
